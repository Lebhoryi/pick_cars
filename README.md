# CARFLEET · 个人选车工作台

![CARFLEET 总览](docs/preview.png)

一个面向个人长期使用的选车管理前端：记录关注车型、核对配置与价格来源、横向对比参数、按个人偏好加权评分，并测算长期持有成本。

- 纯前端、无后端依赖，数据保存在浏览器 `LocalStorage`
- 初始录入 8 款车型（5 款主选 + 3 款竞品：零跑 C10、零跑 C11、大众 ID. AURA T6），其中 **深蓝 S07、长安启源 Q06、比亚迪海狮 06 EV** 标记为重点候选
- 价格、参数、评分、备注、对比清单、成本假设刷新后不丢失
- 重点处理了「数据真实性」：无法核实的字段显示 **待核实**，不编造实时价格；官方/媒体/实测/个人口径分开标注

> 这是个人决策辅助工具，不是车型评测榜单。页面中的评分是**个人偏好模型**，初始手动分数为示例占位，需按试驾和实车体验校准。

## 1. 快速开始

### 环境要求

- Node.js `>= 20.19`（推荐 22 LTS 或 24；本项目在 Node 24 下构建验证）
- npm `>= 10`
- 现代浏览器（Chrome / Edge / Safari / Firefox 近两年版本）

### 安装与启动

```bash
npm install
npm run dev
```

默认监听 `0.0.0.0:5173`，本机和局域网都能开：

- 本机：http://127.0.0.1:5173/
- 局域网（手机 / 另一台电脑，同一网段）：**http://192.168.9.145:5173/**（IP 变了就用 `hostname -I` 或 `ip -4 addr` 看 `ens9f3` 的地址）

### 后台常驻（关掉终端也不停）

```bash
./scripts/dev-lan.sh start      # nohup 后台启动，日志在 .runtime/dev.log
./scripts/dev-lan.sh status     # 状态 + 两个访问地址 + HTTP 码
./scripts/dev-lan.sh log        # 跟随日志
./scripts/dev-lan.sh stop
```

等价 npm 别名：`npm run dev:lan` / `dev:lan:status` / `dev:lan:stop`。

### 开机自动启动

在**你自己的终端**里跑一次（DSH 沙箱内无法写 `~/.config`）：

```bash
./scripts/install-autostart.sh              # 默认 preview 模式，服务 dist/，更轻更稳
./scripts/install-autostart.sh --dev        # 或 dev 模式，带热更新
./scripts/install-autostart.sh --dry-run    # 先看会写什么
./scripts/install-autostart.sh --uninstall  # 卸载
```

- 有 `systemd --user` 时装 `carfleet-preview.service`（`Restart=always`），并尝试 `loginctl enable-linger` 让它开机即起、不依赖登录
- 没有则写 `~/.config/autostart/carfleet-preview.desktop`，登录桌面后拉起
- preview 模式改完代码要 `npm run build` 才生效；要改动立即可见就用 `--dev`

### 局域网打不开时

1. 端口没监听：`./scripts/dev-lan.sh status` 或 `ss -ltnp | grep 5173`
2. 防火墙拦了：`sudo ufw allow 5173/tcp`（`sudo ufw status` 看是否 active）

### 构建与预览

```bash
npm run build
npm run preview
```

静态托管部署时，需要把未知路径回退到 `index.html`（SPA history fallback），否则直接刷新 `/garage/xxx` 会 404。

### 类型检查

```bash
npm run typecheck
```

> 预算默认设为 15–20 万、计划购车日期默认 2027-06-30，均为可修改的初始假设。
>
> 首次安装如果 npm 报缓存目录只读，可指定本地缓存：
> `npm --cache ./.npm-cache --logs-dir ./.npm-logs install`

### 数据真实性设计

- 每个参数都可以标注：**官方 / 媒体 / 经销商 / 实测 / 个人 / 待核实**，并记录来源 URL、核实日期、测试条件、备注。
- 来源链接单独维护，参数通过 `sourceId` 关联到来源；修改来源 URL 后参数引用同步。
- 缺失数据在详情、对比、评分中显示「待核实」，不按 0 分处理；评分只对已填维度算加权，并展示覆盖度。
- 对比表的「最优/较优」只是数值机械判断，页面明确提示「配置多 ≠ 体验好」。
- 价格采用**保守口径**：现金优惠默认计入；附加条件优惠、置换补贴默认不计入，勾选后会在报价记录中明确标注。
- 纯电车型不默认免税：按计划购车日期计算购置税。

### 销量口径（2026 窗口）

销量按**车型 × 月份**逐条记录，单位「辆」。统计窗口固定为：

```
窗口起点 = max(上市月, 2026-01)
窗口终点 = 全库最新已公布月份（当前 2026-10）
累计销量 = 窗口内「已录月份」之和        （缺数据的月份不计 0）
月均销量 = 累计销量 ÷ 已录月份数
数据覆盖 = 已录月份数 ÷ 窗口月数
```

为什么从 2026-01 起算：2026 年起购置税减半、各家口径切换，只做 2026 年以来的同窗口比较；上市晚于 2026-01 的车型从上市月开始算（如 2026-09 上市 → 只统计 9、10 月）。

### 购置税口径

按财政部/税务总局/工信部公告：

- 2024-01-01 至 2025-12-31：免征，减税额上限 3 万元/辆
- **2026-01-01 至 2027-12-31：减半征收（实际 5%），减税额上限 1.5 万元/辆**
- 2028 起：本工具默认按 10% 全额估算

官方原文：https://fgk.chinatax.gov.cn/zcfgk/c102416/c5207352/content.html

计算方式：`不含税价 = 含税成交价 ÷ 1.13`，`应纳税额 = 不含税价 × 10% − 减税额（有上限）`。实际税额以开票时有效政策、车型目录资格与地方执行为准。

> 示例：2027 年购车、含税价 17.28 万，购置税约 0.76 万。工具不会因为「纯电」就自动按 0 处理。

## 4. 评分模型

默认权重：

| 维度 | 权重 |
| --- | ---: |
| 价格与性价比 | 20% |
| 智能驾驶 | 20% |
| 底盘与操控 | 15% |
| 续航与充电 | 15% |
| 空间与舒适性 | 15% |
| 座舱与科技配置 | 10% |
| 品牌、售后与保值 | 5% |

- 权重可随意调整，内部自动归一化为 100%。
- **手动模式**：直接给 7 个维度打 0–10 分；留空表示信息不足。
- 缺失维度不会按 0 分处理：总分 = `Σ(维度分 × 有效权重) / Σ(有效权重)`，同时显示数据覆盖度。
- 硬性条件：最高落地预算、最低 CLTC、城市 NOA 必须标配、必须有激光雷达、仅重点候选；不满足会标记但不删除。
- 排名快照：记录后调整权重可看到「较上次」升降。
- 初始手动评分为**示例占位**（`manualScores`），请按实车体验重新校准。
- 评分只保留**个人手动模型**（自动评分模式已下线）：7 维直接填 0–10 分，留空的维度按权重剔除，不按 0 分算；参数依据仍可在展开行查看。
- 当前排名：**启源 Q06 8.89（第 1）** → 极狐 T7 8.51 → 深蓝 S07 8.45 → 海狮06EV 8.25 → 零跑 C11 8.06 → 零跑 C10 8.03 → MG07 8.00 → ID. AURA T6 7.96。

## 5. 用车成本口径

```
购车落地 = 车价基准 − 现金优惠 − 勾选的附加条件优惠
         + 选装合计 + 智驾包 + 购置税 + 首年保险 + 上牌/其他
         − 勾选的置换补贴

持有总成本 = 购车落地
           + 年能源费 × 年限
           + 第 2 年起保险 × (年限 − 1)
           + 保养 + 轮胎 + 维修
           + 资金机会成本（购车款 × 年化 × 年限）
           − 残值（购车落地 × 残值率）
```

- 年能源费 = `年行驶里程 ÷ 100 × 百公里电耗 × 综合电价`；综合电价按家充/公共比例加权。
- 首年保险已包含在落地价中，第 2 年起单独计；不含停车、路桥、违章、家充桩安装、贷款利息。
- 默认电耗仅在某车型未填写「百公里电耗」时使用；表格里的电耗输入框是临时 what-if，不写入车型参数。
- 不同车型比较时，年限、里程、能源价格、残值率假设保持一致；仅车型电耗/落地价等个体参数不同。
- 所有假设保存在 `settings.cost`，修改后立即重算并持久化。

## 6. 数据与持久化

- `LocalStorage` key：`carfleet.data.v1`；主题单独存 `carfleet.theme`
- 完整数据对象：`vehicles`、`quotes`、`sales`、`reviews`、`testDrives`、`settings`、`scoring`（权重、模式、快照）、`compareIds`
- 自动保存：状态变化后约 320ms 防抖写入；页面隐藏/关闭前会尝试 flush
- 写入失败（如容量不足）会 toast 提示
- 损坏数据：读取失败时备份原文到 `carfleet.corrupt.<timestamp>`，回退到初始示例数据
- JSON 导入：结构校验、车型/报价/销量/车评引用校验、数值/枚举归一化，支持「替换全部」或「合并」
- CSV 导出：车型主表（含累计销量、车评条数）、销量明细（车型×月份）、车评明细、对比表、成本表，均为 UTF-8 BOM

### 导入/导出

- 全量 JSON 包含所有车型、报价、来源、字段级来源、评分权重、快照与设置；换设备时使用「替换全部数据」。
- 合并导入：同 ID 车型覆盖、新车型追加、报价/车评按 ID 去重、销量按「车型 × 月份」覆盖；设置与评分配置采用导入文件。
- 删除确认：删除车型、删除报价、清空数据、恢复示例均有确认弹窗。

### 封面图

- 支持 JPG/PNG/WebP 上传，Canvas 压缩为最长边 1400px 的 JPEG（通常 ≤ 700KB），避免直接塞原图。
- 不设封面时使用自动生成的车侧剪影 + 品牌强调色。
- 本地存储上限因浏览器而异（通常约 5MB），图片较多时请关注「数据管理」中的占用条。

## 8. 已知限制

1. **没有实时价格/库存/金融方案**：所有报价为人工录入，无法保证 4S 店当期政策。
2. **部分参数为空**：例如 MG07 的尺寸/电池/智驾硬件、深蓝 S07 的尺寸/悬架、启源 Q06 的官方来源字段；界面会显示「待核实」，不做补齐。
3. **版本/年款冲突**：MG07「610 旗舰版」、海狮06EV「605 旗舰版」未能与官方配置器完全对齐，已标记待核实；不要将这些配置直接用于最终下单。
4. **初始评分为示例**：`manualScores` 是演示占位，不是真实试驾结论。
5. **购置税为估算**：政策、目录资格、开票时间与地方补贴可能变化；本工具只做数量级参考。
6. **成本为模型**：不含停车、路桥、违章、家充安装、贷款利息；残值/机会成本为用户假设。
7. **LocalStorage 容量有限**：大量高清封面可能触及 5MB；务必定期导出 JSON。
8. **无多端同步**：数据只在当前浏览器；换设备需 JSON 导入。
9. **外观图来自官方**：取自品牌官网/官方通稿，版权归品牌方，仅个人参考；车型改款后图片可能与实车配色/细节不一致。
10. **车评是账号观点**：只收两个 UP 主，结论带个人立场与商业环境；原话经 Whisper 转录，可能有同音错字。同一台车在不同视频、与实测之间都可能矛盾，冲突时以试驾与配置表为准。
11. **销量拆分滞后**：单车型月度销量依赖品牌战报或乘联会榜单（次月中旬），品牌只报合计时只能留「待核实」；口径（批发/交付/零售）不统一，累计值不可直接当作排名。
12. **未做自动化测试**：已通过 TypeScript 类型检查与构建；交互路径为手工/Playwright 冒烟验证。
